COODE

Türkçe konuşan kişisel yapay zeka asistanı

Windows için indirCoode_Setup.exe — çift tıkla, kur Android için indirCoode.apk — dokun, yükle
Kurulumdan sonra: Coode ücretsiz bir Groq anahtarı ister. console.groq.com/keys → Create API Key → kopyala, Coode'a yapıştır.

Windows "bilinmeyen yayıncı" derse: Ek bilgi → Yine de çalıştır.
Android izin isterse: "Bu kaynaktan yüklemeye izin ver".
